Know what you get

Two files. Two different jobs.

The pickit tells Exiled Bot what the generated rules select. The optional loot filter controls what you see on the ground in Path of Exile.

.ipd

Bot pickit

Used by Exiled Bot. Your pickit.ini needs to point to this generated filename.

.filter

In-game loot filter

Used by Path of Exile. Select it again under Options → Game → Filters after every save or regeneration. Generated for Path of Exile 2; in Path of Exile 1 the app writes only the .ipd, and Create your filter still converts any pickit you bring.

v4.55.1Current release · 29 July 2026

Maps, end to end.

Path of Exile 1 now gets map pickup rules, the bot’s own map-runner file, tier upgrading for everything below your selection — and a check that your bot is set up to read it.

  • v4.50.0 · Gems priced as they drop, and a pill that stops lying — poe.ninja lists a skill gem once per level/quality/corrupted combination and returns them dearest-first, and the generator kept the first row — so Frostblink was written as 7,853 ex, the price of a level-20 quality-20 CORRUPTED one, when the gem that falls on the ground is worth 1. Measured against a live league, 666 of 810 gems were overstated by tenfold or more. That made the value floor useless for gems, since every one of them cleared any floor on the strength of a variant it will never be. Gems are now priced from the row a dropped gem actually matches, with the best roll still noted in the comment. The Economy table’s “keep” pill also stopped describing the wrong thing: it only ever showed whether you had manually excluded an item, never whether it clears your floor, so a cheap tablet sat there in green saying “keep” while the generator wrote that same rule commented out. Read the v4.50.0 notes.
  • v4.49.0 · What your bot actually did, and 850 rules that could never match — everything this app reported until now was about what it wrote. Exiled Bot keeps its own Log/lastrun.log, and two lines in it are the only evidence any of it reached the game: which pickit it loaded and how many rules it got, and every item it picked up. The count the bot reports is exactly this app’s “active rules” figure, so the check is exact rather than a guess — if the bot last loaded a different number than you last wrote, it is still running the OLD pickit and the History page says so. The same release fixes 850 cluster-jewel rows that were being written as rules that could never match: poe.ninja prices cluster jewels by their ENCHANTMENT, so a row is named “Minions deal 10% increased Damage” while the item is a plain Large Cluster Jewel, and those sentences went straight into [Type]. They now name the real base, priced at the median of their variants — what a random drop is actually worth — so they sit commented out below any real floor with the reason beside them. Read the v4.49.0 notes.
  • v4.48.5 · Loading and empty states — tables that are still loading show their shape instead of nothing. Economy filled about a hundred rows in one go, reflowing the page under your cursor, and the two Maps tables simply read “Loading…”. They draw skeleton rows now, so nothing jumps when the data lands. Three details make it honest rather than decorative: a refresh keeps the rows you were already reading, a failed load clears the skeleton and names the error with a Retry button, and a test enforces that — a skeleton that outlives its request is just the old “Loading prices…” hang wearing a nicer coat. History also gained a real empty state instead of “No runs yet.” in a bare table cell, and the stat tiles count up rather than snapping from a dash to 2,214 — honouring the reduce-motion setting the app started respecting last release. Read the v4.48.5 notes.
  • v4.48.4 · Polish: the keyboard, and affordances that lied — a sweep over every tab. You can now see where the keyboard is: text boxes picked up a gold border when focused, but buttons, dropdowns and links showed nothing at all, and three rules explicitly switched the outline off — so tabbing through the app was a guess. Everything focusable draws a ring now, and only for keyboard use, so clicking with a mouse looks exactly as it did. The tab rail answers the keyboard too: it was a column of plain divs that could not be focused at all, leaving Ctrl+1..0 as the only way in — and that reaches ten of the sixteen tabs. Sixteen of nineteen table headers also stopped pretending to be clickable: only the three Economy columns sort, but every header in the app showed a hand cursor and lit up on hover. Selected text finally uses the app’s own colour rather than the browser’s default blue, and if Windows is set to reduce motion the app honours it. Read the v4.48.4 notes.
  • v4.48.3 · Quality of life: the bot’s switches, and the keyboard — the Maps page already read map_profile and enable_map_tier_upgrading out of your bot’s config.ini and told you what to change, which still left you hand-editing an INI inside your bot install to finish a job this app started. A Set these for me button now does it, and appears only when something is actually wrong. It is someone else’s file, so it is edited carefully: the original is backed up, only those two keys are rewritten, and comments, ordering, unknown sections and even non-UTF-8 bytes come back out untouched. Ctrl+R also refreshes the league list as its button has always claimed — nothing implemented it, so the key fell through to the webview and reloaded the whole app — and Escape now clears the search box you are typing in. Read the v4.48.3 notes.

Straight answers

Before you download.

Is this the bot?

No. It is a generator for Exiled Bot pickit files and optional Path of Exile loot filters.

Can I convert a pickit made somewhere else?

Yes. Drop any Exiled Bot .ipd into the app. The source stays read-only, and the report explains anything the game filter cannot express exactly.

What happens when a rule cannot be translated exactly?

The report marks it as Shown wider or Untranslatable, then gives the source line and reason. Review every warning before relying on Hide everything else.

Why was an item missed when Item Check says Picked up?

Item Check reports what the generated pickit says. Run the connection check and confirm that pickit.ini points to that same generated file.

What does “Depends on the rolls” mean?

The generated pickit covers that rare base, but Exiled Bot scores the item’s actual modifiers in game. Item Check shows the scored stats and threshold instead of inventing a final answer.

Should I leave Hide everything else on?

It starts off and remembers your choice; gold is never hidden. Keep it off while botting because hidden labels can stall pickup.

Why didn’t my in-game filter update after regeneration?

Path of Exile may still have the previous filter loaded. After saving or regenerating, select the .filter again under Options → Game → Filters.

Where are generated files saved, and are backups made?

The app writes the generated .ipd and optional .filter to your chosen output folder. Rotating backups protect generated output before replacement and can be restored from Settings.

Why does Windows show a warning?

The app is not code-signed. Its source, build workflow, and SHA-256 checksum are public, so the downloaded executable can be verified.
